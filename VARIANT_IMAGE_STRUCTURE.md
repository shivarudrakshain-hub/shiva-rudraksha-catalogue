# Variant image folders

Use lowercase folder names:

- small
- medium
- large
- collector
- super-collector

Each folder uses AVIF files:

- front.avif
- back.avif
- top.avif
- bottom.avif
- certificate.avif
- xray.avif

Example:

`public/images/products/13-mukhi-nepal-rudraksha/small/front.avif`

The original product-level `.avif` images remain as fallbacks if a size-specific `.avif` file is missing.
